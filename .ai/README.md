# Basic Android AI Development Prompt Pack

Copy the `.md` files into your Android repository.

Recommended location:

```text
.ai/
├── 00_MASTER_PROMPT.md
├── 01_PROJECT_STRUCTURE.md
├── 02_NETWORK_AND_REPOSITORY.md
├── 03_DATASTORE_HILT_VIEWMODEL.md
└── 04_COMPOSE_AND_TESTING.md
```

Start every AI coding session with `00_MASTER_PROMPT.md`.

Use the other files as focused rules when working on architecture, networking, local storage, ViewModels, Compose, or testing.

These files intentionally contain architecture rules rather than fixed library versions, so the project can use compatible current versions.
